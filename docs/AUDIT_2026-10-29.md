# Source-code audit | 29 October 2026

**Scope:** Original privately supplied Shongwe Motors Python/PyQt5 source archive, not yet committed to this public repository. Original ZIP SHA-256: c907eac6c995de2bfb9a23c67daa5d6e9f76b7cde2a3510d4a1d2aa0d5a52d50.

**Examined:** main.py (490 lines), database.py (194 lines), database_setup_mysql.sql, four Qt Designer .ui files, requirements.txt, launch scripts and README. No original production database was modified.

**Method:** Python AST parse, XML/Qt object-name verification, reading and tracing SQL and controller flow, isolated disposable SQLite databases, reproducible pytest suite.

**Evidence:** 15 baseline tests passed, 7 strict expected failures reproduced missing safeguards. Additional probes: two overlapping same-slot vehicle bookings accepted; deleting either linked customer or vehicle removed its booking; deleting the most recent customer caused its human-readable code to be reusable; negative price/mileage and invalid time accepted; FK rejection of unknown records worked. Live Qt/Windows GUI execution and cross-process concurrency testing remain outstanding.

## Verified working foundations

Four Qt Designer pages, controller navigation, forms and lists for customers and vehicles, test drive and other appointment types, calendar/date/time widgets, live vehicle clock and SQLite persistence. Queries use parameters; uniqueness constraints exist for customer, vehicle and booking codes, identification numbers and VINs; each new SQLite connection enables foreign keys. The MySQL schema file is illustrative only, with no runtime MySQL connection.

## Conflict-prevention design

A unique (vehicle, date, time) index protects identical active starts but **does not protect overlapping intervals**. Add canonical start/end datetime and active/cancelled states. Reject existing.start < requested.end AND existing.end > requested.start for a shared resource. Serialize write checks and insertion under a single BEGIN IMMEDIATE transaction; index active starts for defence in depth. Decide whether consultant and customer may overlap, and how Reserved/Sold status affects eligibility. Adjacent appointments ending exactly at the next start should pass.

## Migration and security constraints

Do not add a uniqueness constraint until existing duplicate slots are identified and resolved without silent deletion. Preserve legacy codes and related histories; apply all migrations first to copies and verify counts, FK integrity and restore. Remove plaintext credentials before publishing source. Local desktop login does not by itself defend against another OS user who has filesystem write access to the DB; document that boundary honestly.

## Limitations

PyQt5 was unavailable in the audit runtime and package installation was blocked. Therefore real GUI startup, Windows compatibility, integration with system dialogs, secure installation, migration from real populated data, performance and multiple-process races are **unverified**. This audit is not a production security certification.
